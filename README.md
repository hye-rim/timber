# 나무꾼 🪓

화면 왼쪽·오른쪽을 눌러 나무를 베며 올라가는 원터치 반응 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 화면 **왼쪽/오른쪽**을 누르거나 `←` `→`(`A` `D`). 누른 쪽으로 나무꾼이 옮겨 가서 맨 아래 마디를 벱니다. `M` 소리. 창이 가려지면 저절로 일시정지.
- 규칙: 베고 나면 위 마디가 내려오는데, 그 마디의 가지가 내가 선 쪽에 있으면 부딪혀서 끝. 시간 게이지가 다 닳아도 끝. 가지 없는 쪽은 항상 있으니(가지는 마디마다 한쪽만, 최대 3마디 이어짐) **반응 속도가 전부**입니다. 첫 번째 베기 전에는 게이지가 줄지 않습니다.
- 게이지: 베면 차오르고(쉬움 0.06 · 보통 0.05 · 어려움 0.045) 가만있으면 줄며, 점수가 오를수록 닳는 속도가 빨라지다 상한(쉬움 0.38 · 보통 0.32 · 어려움 0.40/초)에서 멈춥니다. 초당 6번을 벨 수 있는 사람도 결국 끝나도록 상한을 잡았습니다.
- 최고 기록은 `timberBest`(벤 횟수). `logic.js` 규칙(`LOGIC_TIMBER`), `game.js` 화면·입력·소리, `test/logic.test.js` (`node --test`).

## 오늘의 판 · 연패 구제

- 시작 화면의 **📅 오늘의 판**(보통 난이도): 날짜가 시드라 같은 날에는 누구나 같은 나무가 나옵니다. 결과 화면에 오늘 최고와 공유 버튼이 나옵니다(`arcade/public/daily.js`).
- **연패 구제**: 보통·어려움에서 15번(어려움은 10번)도 못 베고 끝나는 판이 3번 연속이면 「쉬움으로 해 볼까요?」 안내가 뜹니다(`arcade/public/assist.js`). 결과 화면에 난이도 단추가 있어야 안내가 뜨므로 결과 화면에도 쉬움·보통·어려움 단추를 둡니다. 기준값은 정한 값이라 실제 플레이로 조정이 필요합니다.
